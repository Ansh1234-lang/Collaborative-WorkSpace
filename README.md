🚀 Collaborative Workspace

A modern, full-stack **real-time collaborative workspace** designed to help teams organize projects, manage tasks, and collaborate efficiently.

The application provides workspaces, Kanban boards, task management, user authentication, activity tracking, and real-time collaboration through WebSockets.

## 📌 What is Collaborative Workspace?

Collaborative Workspace is a project-management platform where users can create workspaces and organize their work using Kanban-style boards.

Instead of managing tasks through scattered messages or documents, users can keep projects, tasks, members, deadlines, and activity in one place.

### Main workflow

```text
Register / Login
       ↓
Create Workspace
       ↓
Create / Manage Projects
       ↓
Create Board
       ↓
Create Columns
       ↓
Create Tasks / Cards
       ↓
Assign Members
       ↓
Move Tasks with Drag & Drop
       ↓
Collaborate in Real Time
